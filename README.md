# 📸 Selfie-Based Smart Attendance — AI Face Recognition

A smart attendance system that uses **AI-powered facial recognition** to automatically identify employees or students through a selfie and record their attendance. It provides a fast, contactless, and secure alternative to traditional attendance methods while reducing manual errors and attendance fraud.

### 🧠 AI Face Detection

The system uses AI-powered face detection to accurately identify and analyze faces under different conditions, including:

* 👤 **Face Detection** — Detects and locates faces in real time.
* 🕶️ **Sunglasses Detection** — Identifies faces wearing sunglasses.
* 🌙 **Low-Light Detection** — Detects and handles faces in low-light environments.
* 😷 **Mask Detection** — Identifies faces wearing masks.
* 👥 Multiple Faces Detection — Checks if multiple faces are present in the frame simultaneously, showing the popup "Only one person allowed" if more than one face is detected.
